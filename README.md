# IOSOR — B2B Telecom Decision Intelligence & Verified Partner Matrix

**IOSOR** ([iosor.com](https://iosor.com/?lang=en)) is a Switzerland-based B2B telecom decision intelligence and verified partner comparison platform (Vallorbe / Lausanne area, Canton of Vaud, Switzerland; Swiss Trademark App. No. `20723/2026`), founded by **Oleksandr (Alex) Petukhov**.

Engineering, product, and procurement teams use IOSOR without login or paywalls to evaluate **64 verified B2B messaging, voice, and email providers** (**2,016 head-to-head 1v1 comparisons**) across **SMS, OTP/2FA, Voice SIP, Virtual Numbers (DID), E.164 Lookup, Transactional Email, and WhatsApp/RCS** — backed by **11 Edge engineering tools**, **56,715+ verified Expert Q&A entries**, and **9,261+ operational engineering guides in 44 languages**.

> **Architecture note:** The live production application (`iosor-os/IOSOR_SITE.10.8v`) is maintained in a private monorepo and deployed via Wrangler CLI onto **Cloudflare Pages + Next.js Edge Runtime + Cloudflare Workers** (`https://iosor.com`). This public repository serves as the public documentation index and machine-readable reference point.

## Core Engineering Capabilities

- **Decision Brief (`/tools/brief?lang=en`)** — matches telecom job, destination corridor, monthly volume, and compliance gates to an indicative comparison and verified partner shortlist.
- **11 Live Edge Tools** — Latency Radar (`p50`/`p95`/`p99` & 90-day uptime), 195-Country Compliance Atlas (`10DLC`, `TRAI DLT`, `SGNIC`, `MEF`, `GDPR`), Protocol Inspector (`GSM-7` / `UCS-2` / `SPF` / `SIP`), 4-Currency TCO & Migration ROI Calc (`USD`, `EUR`, `GBP`, `CHF`), Dual-Rail Failover Blueprint (`TS`, `Python`, `Go`, `JSON`), DLR Webhook & Error Lab, E.164 & Sender Pre-Flight, Quiet Hours Planner, Opt-Out & Consent Lab, AIT Fraud Shield, and SVG/OpenAPI/MCP Trust Badges.
- **Global 44-Language Localization** — independent native engineering documentation (`9,261+` guides) and verified Expert Q&A (`56,715+` answers) across 44 locales.
